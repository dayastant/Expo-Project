# React Native Map Snapshot & Search App

A React Native app integrating **Google Maps** and **Google Places Autocomplete**. Users can search for locations, zoom into their current position, focus on predefined regions, and take snapshots of the map to share.

## Features

- Interactive **Google Map**  
- **Search locations** with Google Places Autocomplete  
- **Focus** map on predefined locations (e.g., New York)  
- **Zoom** into current location  
- **Take snapshot** and share  
- Handles **location permissions** via Expo  
- Clean UI with floating action buttons
